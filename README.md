# 縦読み - 일본어 세로쓰기 PDF 추출기

오른쪽 열에서 왼쪽 열로, 각 열은 위에서 아래로 읽는 일본어 PDF를 UTF-8 TXT로 변환하는 브라우저 앱입니다.

## 사용법

1. 웹앱에 PDF를 끌어놓거나 `PDF 선택`을 누릅니다.
2. 자동 감지가 먼저 PDF의 텍스트 레이어를 확인합니다.
3. 결과를 검토하고 필요하면 설정을 바꾼 뒤 `설정으로 다시 추출`을 누릅니다.
4. 결과를 직접 고친 뒤 `복사` 또는 `TXT 저장`을 누릅니다.

## 추출 방식

- 텍스트 PDF: 각 글자의 좌표를 열로 묶고, 열은 우→좌, 글자는 상→하 순서로 정렬합니다.
- 스캔 PDF: 텍스트가 거의 없는 페이지만 일본어 세로쓰기 OCR(`jpn_vert`)을 적용합니다.
- 후리가나 제거: 본문보다 작은 일본어 글자를 찾아 제외합니다.
- 문장부호: 세로쓰기 전용 괄호와 구두점을 일반 텍스트 문자로 바꿉니다.

PDF 내용은 브라우저 안에서 처리됩니다. OCR을 처음 실행할 때에만 일본어 인식 모델을 인터넷에서 내려받으며, PDF 페이지 이미지는 OCR 서버로 업로드되지 않습니다.

## 로컬 실행

Node.js가 설치된 Windows에서는 `실행.bat`을 더블클릭합니다. 또는 터미널에서 아래 명령을 실행합니다.

```text
npm install
npm run dev
```

그 뒤 `http://localhost:3000`을 엽니다.

## 알아둘 점

- 인용문, 표, 본문과 주석이 복잡하게 섞인 판면은 원문 대조가 필요할 수 있습니다.
- OCR 정확도는 해상도, 기울기, 종이 얼룩, 옛 글자체의 영향을 받습니다.
- 비밀번호로 잠긴 PDF는 먼저 잠금을 해제해야 합니다.
