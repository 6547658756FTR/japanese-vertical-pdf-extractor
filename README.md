# 縦読み - 일본어 세로쓰기 PDF 추출기

오른쪽 열에서 왼쪽 열로, 각 열은 위에서 아래로 읽는 일본어 PDF를 UTF-8 TXT로 변환하는 브라우저 앱입니다.

## 사용법

1. 웹앱에 PDF를 끌어놓거나 `PDF 선택`을 누릅니다.
2. 자동 감지가 먼저 PDF의 텍스트 레이어를 확인합니다.
3. 결과를 검토하고 필요하면 설정을 바꾼 뒤 `설정으로 다시 추출`을 누릅니다.
4. 결과를 직접 고친 뒤 `복사` 또는 `TXT 저장`을 누릅니다.

## 추출 방식

- 텍스트 PDF: 각 글자의 좌표를 열로 묶고, 열은 우→좌, 글자는 상→하 순서로 정렬합니다.
- 스캔 PDF: 텍스트가 거의 없는 페이지만 일본어 세로쓰기 OCR(`jpn_vert`)을 적용합니다.
- 후리가나 처리: 작은 루비를 제거하거나 `漢字（かんじ）`처럼 괄호로 표시합니다.
- 문장부호: 세로쓰기 전용 괄호와 구두점을 일반 텍스트 문자로 바꿉니다.
- 대화문: `「`부터 `」`까지는 기본적으로 한 줄로 묶고, 필요하면 `「」 앞뒤 줄바꿈` 버튼으로 대화문 경계도 줄 단위로 나눕니다.

PDF 내용과 추출 결과는 브라우저 메모리 안에서만 처리되며 서버로 전송하거나 저장하지 않습니다. 일본어 OCR 실행 파일과 인식 모델도 웹앱에 포함되어 있어 변환 중 외부 OCR 서비스에 접속하지 않습니다. OCR 캐시, 쿠키, Local Storage, IndexedDB에도 사용자 문서를 저장하지 않으며 페이지를 닫으면 메모리의 PDF와 결과도 사라집니다.

## 보안 설계

- 파일 이름·MIME 유형·PDF 헤더와 파일 크기(최대 100MB), 페이지 수(최대 2,000쪽)를 검증합니다.
- PDF 내용은 HTML로 렌더링하지 않고 텍스트 영역의 값으로만 표시합니다.
- 오류 화면에는 내부 스택이나 라이브러리 상세정보를 노출하지 않습니다.
- PDF 버퍼, OCR 캔버스와 작업자는 처리가 끝나거나 실패하면 즉시 해제합니다.
- 콘텐츠 보안 정책으로 외부 연결과 플러그인 객체 실행을 제한합니다.

## GitHub Pages

저장소의 GitHub Pages 소스를 `GitHub Actions`로 지정하면 포함된 워크플로가 정적 웹앱을 빌드하고 게시합니다. 게시된 페이지는 서버 API, 데이터베이스, 분석 도구, 쿠키 및 브라우저 저장소를 사용하지 않습니다.

> **주의:** 비공개 저장소와 비공개 웹사이트는 서로 다릅니다. 일반 GitHub Pages 주소는 저장소가 비공개여도 인터넷에 공개될 수 있으며, `noindex`는 검색 노출을 줄일 뿐 접근 제어가 아닙니다. 다만 이 앱에 넣는 PDF와 변환 결과는 게시 사이트로 업로드되지 않습니다.

## 로컬 실행

Node.js가 설치된 Windows에서는 `실행.bat`을 더블클릭합니다. 또는 터미널에서 아래 명령을 실행합니다.

```text
npm install
npm run dev
```

그 뒤 `http://localhost:3000`을 엽니다.

## 알아둘 점

- 인용문, 표, 본문과 주석이 복잡하게 섞인 판면은 원문 대조가 필요할 수 있습니다.
- OCR 정확도는 해상도, 기울기, 종이 얼룩, 옛 글자체의 영향을 받습니다.
- 비밀번호로 잠긴 PDF는 먼저 잠금을 해제해야 합니다.
