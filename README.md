# 縦読み - 일본어 세로쓰기 PDF·이미지 추출기

오른쪽 열에서 왼쪽 열로, 각 열은 위에서 아래로 읽는 일본어 PDF·PNG·JPG를 UTF-8 TXT로 변환하는 브라우저 앱입니다.

## 사용법

1. 웹앱에 PDF·PNG·JPG를 여러 개 끌어놓거나 `파일 선택`을 누릅니다. PNG·JPG는 페이지에서 `Ctrl+V`로 여러 번 붙여넣을 수도 있습니다.
2. 파일 목록과 처리 순서를 확인하고 페이지 구성을 포함한 추출 설정을 선택합니다.
3. `인식 시작`을 누르면 PDF는 텍스트 레이어를 먼저 확인하고, 이미지 파일은 일본어 세로쓰기 OCR을 적용합니다.
4. 결과를 검토하고 필요하면 설정을 바꾼 뒤 `설정으로 다시 추출`을 누릅니다.
5. 결과를 직접 고친 뒤 `복사` 또는 `TXT 저장`을 누릅니다.

## 추출 방식

- 텍스트 PDF: 각 글자의 좌표를 열로 묶고, 열은 우→좌, 글자는 상→하 순서로 정렬합니다.
- 스캔 PDF: 텍스트가 거의 없는 페이지만 일본어 세로쓰기 OCR(`jpn_vert`)을 적용합니다.
- PNG·JPG: 이미지 형식과 해상도를 확인한 뒤 일본어 세로쓰기 OCR(`jpn_vert`)을 적용합니다.
- 상·하 두 단: 상단 블록의 세로 열을 모두 우→좌로 읽은 다음 하단 블록의 세로 열을 우→좌로 읽습니다. OCR 이미지는 위·아래로 나눠 같은 순서로 처리합니다.
- 여러 파일: 선택·드래그·클립보드 붙여넣기로 담은 순서대로 처리하며, 파일을 담는 것만으로는 인식을 시작하지 않습니다.
- 후리가나 처리: 작은 루비를 제거하거나 `漢字（かんじ）`처럼 괄호로 표시합니다.
- 문장부호: 세로쓰기 전용 괄호와 구두점을 일반 텍스트 문자로 바꿉니다.
- 자동 줄바꿈: 글자가 아래쪽까지 찬 세로 열에서 다음 열이 위쪽부터 이어지면 같은 문단으로 붙이고, 짧게 끝난 열이나 들여쓴 새 문단만 줄을 바꿉니다.
- 페이지 경계: 앞쪽 페이지가 마침표·물음표·느낌표·닫는 괄호로 끝나지 않으면 다음 페이지의 문장이 이어진 것으로 보고 줄바꿈을 넣지 않습니다. 다음 페이지가 닫는 문장부호로 시작하는 경우도 이어 붙입니다.
- 대화문: `「`부터 `」`까지는 기본적으로 한 줄로 묶고, 필요하면 `「」 앞뒤 줄바꿈` 버튼으로 대화문 경계도 줄 단위로 나눕니다.

PDF·이미지 내용과 추출 결과는 브라우저 메모리 안에서만 처리되며 서버로 전송하거나 저장하지 않습니다. 일본어 OCR 실행 파일과 인식 모델도 웹앱에 포함되어 있어 변환 중 외부 OCR 서비스에 접속하지 않습니다. OCR 캐시, 쿠키, Local Storage, IndexedDB에도 사용자 문서를 저장하지 않으며 페이지를 닫으면 메모리의 파일과 결과도 사라집니다.

## 보안 설계

- 파일 이름·파일 서명·파일 크기(최대 100MB), PDF 페이지 수(최대 2,000쪽), 이미지 해상도를 검증합니다.
- PDF 내용은 HTML로 렌더링하지 않고 텍스트 영역의 값으로만 표시합니다.
- 오류 화면에는 내부 스택이나 라이브러리 상세정보를 노출하지 않습니다.
- PDF·이미지 버퍼, OCR 캔버스와 작업자는 처리가 끝나거나 실패하면 즉시 해제합니다.
- 콘텐츠 보안 정책으로 외부 연결과 플러그인 객체 실행을 제한합니다.

## GitHub Pages

저장소의 GitHub Pages 소스를 `GitHub Actions`로 지정하면 포함된 워크플로가 정적 웹앱을 빌드하고 게시합니다. 게시된 페이지는 서버 API, 데이터베이스, 분석 도구, 쿠키 및 브라우저 저장소를 사용하지 않습니다.

> **주의:** 비공개 저장소와 비공개 웹사이트는 서로 다릅니다. 일반 GitHub Pages 주소는 저장소가 비공개여도 인터넷에 공개될 수 있으며, `noindex`는 검색 노출을 줄일 뿐 접근 제어가 아닙니다. 다만 이 앱에 넣는 파일과 변환 결과는 게시 사이트로 업로드되지 않습니다.

## 로컬 실행

Node.js가 설치된 Windows에서는 `실행.bat`을 더블클릭합니다. 또는 터미널에서 아래 명령을 실행합니다.

```text
npm install
npm run dev
```

그 뒤 `http://localhost:3000`을 엽니다.

## 알아둘 점

- 인용문, 표, 본문과 주석이 복잡하게 섞인 판면은 원문 대조가 필요할 수 있습니다.
- OCR 정확도는 해상도, 기울기, 종이 얼룩, 옛 글자체의 영향을 받습니다.
- 비밀번호로 잠긴 PDF는 먼저 잠금을 해제해야 합니다.

## 개인정보 보호와 파일 검증

파일 내용과 추출 결과는 브라우저 메모리에서만 처리되며 업로드·저장되지 않습니다. 붙여넣은 이미지도 같은 방식으로 로컬에서만 처리합니다. 파일 확장자뿐 아니라 PDF·PNG·JPEG 파일 서명을 검사하며, 과도한 이미지 해상도는 처리 전에 거부합니다. 한 번에 최대 50개, 합계 300MB까지 목록에 담을 수 있습니다.
